# Premnath J K Portfolio

A responsive developer portfolio created from the information in Premnath J K's resume.

## Run locally
Open `index.html` directly in a browser, or use VS Code Live Server.

## Deploy to Vercel
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `assets`.
3. Import the repository into Vercel.
4. Use the default settings and deploy.

No build command is required because this is a static HTML/CSS/JS site.

## Customize
- Edit `index.html` for portfolio content.
- Edit `style.css` for colors/layout.
- Edit `script.js` for interactions.
- Put profile/resume files inside `assets/`.
